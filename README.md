# Portfolio de Mohamed Fadel

Site statique en français. Pour l’ouvrir sur ton ordinateur, double-clique sur `index.html`. Le contenu se modifie dans ce fichier. Les couleurs, la typographie et la mise en page se modifient dans `styles.css`.

## Fichiers

```text
portfolio/
├── index.html
├── styles.css
└── README.md
```

## Publier sur GitHub Pages

1. Décompresse l’archive.
2. Depuis ton compte GitHub, crée le dépôt public `Fadel1222.github.io`, ou ouvre-le s’il existe déjà.
3. Ajoute les trois fichiers à la racine de la branche `main`, puis valide le commit. Dépose les fichiers directement à la racine du dépôt.
4. Dans **Settings → Pages**, choisis **Deploy from a branch**, puis **main** et **/(root)**. Clique sur **Save**.
5. Une fois le déploiement terminé, ouvre [fadel1222.github.io](https://fadel1222.github.io/).

[Guide officiel de GitHub Pages](https://docs.github.com/en/pages/quickstart)
